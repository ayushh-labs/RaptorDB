# Architectural Decision Records (ADRs)

We document significant architectural decisions in this directory using Architectural Decision Records (ADRs).

## ADR Process

1. Create a copy of the [ADR Template](adr_template.md).
2. Number the records sequentially (e.g., `0001-record-format.md`).
3. Propose the decision in a Pull Request for maintainer review.
4. Once merged, the ADR is considered accepted.
